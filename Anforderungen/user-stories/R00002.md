# User Stories zu R00002 — Spalten gestalten

## US-1: Weitere Spalte anlegen

**Als** Nutzer von KanbanC
**möchte ich** einem Board eine zusätzliche Spalte geben,
**damit** das Board meinen Arbeitsfluss abbildet statt der Standardvorlage.

- **Gegeben** ein Board mit den drei Standardspalten „Zu erledigen", „In Arbeit", „Erledigt"
- **Wenn** ich eine Spalte „Wartet auf Zulieferung" anlege
- **Dann** steht sie als vierte in der Spaltenliste
- **Und** ihre Position ist 4

## US-2: Spalte umbenennen

**Als** Nutzer von KanbanC
**möchte ich** die Bezeichnung einer Spalte ändern,
**damit** ich die Vorlagennamen durch meine eigenen ersetzen kann.

- **Gegeben** ein Board mit der Spalte „In Arbeit"
- **Wenn** ich sie in „In Umsetzung" umbenenne
- **Dann** zeigt die Spaltenliste „In Umsetzung"
- **Und** die Spalte steht unverändert an derselben Position

## US-3: Spalten umsortieren

**Als** Nutzer von KanbanC
**möchte ich** die Reihenfolge der Spalten ändern,
**damit** sie der Richtung entspricht, in der die Arbeit tatsächlich fließt.

- **Gegeben** ein Board mit den Spalten „Zu erledigen" (1), „In Arbeit" (2), „Erledigt" (3)
- **Wenn** ich „Erledigt" an den Anfang schiebe
- **Dann** lautet die Reihenfolge „Erledigt", „Zu erledigen", „In Arbeit"
- **Und** die Positionen sind lückenlos 1, 2, 3

## US-4: Spalte entfernen

**Als** Nutzer von KanbanC
**möchte ich** eine Spalte entfernen, die ich nicht brauche,
**damit** das Board nicht mit leeren Bahnen zugestellt ist.

- **Gegeben** ein Board mit drei Spalten
- **Wenn** ich die mittlere Spalte entferne
- **Dann** zeigt die Liste nur noch die beiden übrigen
- **Und** deren Positionen sind 1 und 2

## US-5: Board ohne Spalten

**Als** Nutzer von KanbanC
**möchte ich** auch die letzte Spalte entfernen können,
**damit** ich die Struktur eines Boards von Grund auf neu aufbauen kann.

- **Gegeben** ein Board mit genau einer Spalte
- **Wenn** ich diese Spalte entferne
- **Dann** bleibt das Board bestehen und zeigt eine leere Spaltenliste
- **Und** ich kann danach eine neue Spalte anlegen, die Position 1 bekommt

## US-6: Spalte als Abschlussspalte markieren

**Als** Nutzer von KanbanC
**möchte ich** einer Spalte eine Anzeigegrenze geben,
**damit** eine volllaufende Spalte die Ansicht nicht erschlägt, sondern nur die neuesten Einträge zeigt.

- **Gegeben** ein Board mit der Spalte „Abgenommen" ohne Markierung
- **Wenn** ich sie als Abschlussspalte mit der Anzeigegrenze 10 markiere
- **Dann** zeigt die Spaltenliste sie als Abschlussspalte mit Anzeigegrenze 10
- **Und** eine bereits markierte zweite Spalte „Erledigt" behält ihre eigene Grenze 20

## US-7: Unvollständige Eingabe wird zurückgewiesen

**Als** Nutzer von KanbanC
**möchte ich** eine verständliche Rückmeldung bekommen, wenn meine Eingabe nicht reicht,
**damit** ich den Fehler korrigieren kann, statt vor einer kaputten Seite zu stehen.

- **Gegeben** die Spaltenpflege eines Boards ist geöffnet
- **Wenn** ich eine Spalte ohne Bezeichnung anlegen will
- **Dann** erscheint eine lesbare Fehlermeldung
- **Und** es entsteht keine Spalte — die Liste ist unverändert

## US-8: Markierung ohne Anzeigegrenze wird zurückgewiesen

**Als** Nutzer von KanbanC
**möchte ich**, dass eine Abschlussspalte ohne Grenze abgelehnt wird,
**damit** keine Spalte entsteht, bei der unklar ist, wie viel sie überhaupt lädt.

- **Gegeben** die Spaltenpflege eines Boards ist geöffnet
- **Wenn** ich eine Spalte als Abschlussspalte markiere und das Feld Anzeigegrenze leer lasse
- **Dann** erscheint eine lesbare Fehlermeldung
- **Und** die Spalte bleibt unmarkiert

## US-9: Ein Agent gestaltet die Spalten über die API

**Als** KI-Agent
**möchte ich** die Spaltenstruktur eines Boards über die API setzen,
**damit** ich ein Board vorbereiten kann, ohne dass ein Mensch klickt.

- **Gegeben** ein Board mit den drei Standardspalten
- **Wenn** ich per `POST` eine vierte Spalte anlege und per `PUT` auf `/spalten/reihenfolge` die gewünschte Ordnung sende
- **Dann** liefert `GET /api/boards/{id}` die vier Spalten in genau dieser Ordnung
- **Und** die Positionen sind lückenlos 1 bis 4
