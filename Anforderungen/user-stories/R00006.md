# User Story R00006: Karten anlegen und am Board sehen

## Wer, wie, warum

**Wer:** Ein Mensch, der sein Board im Browser führt — und ein KI-Agent, der über die API dieselbe Arbeit tut.

**Wie:** Der Mensch öffnet ein Board und sieht in jeder Bahn die Aufgaben, die dort liegen, in der Reihenfolge, in der sie stehen. Am Fuß einer Bahn legt er eine neue Aufgabe an; sie erscheint unten in derselben Bahn. Der Agent tut dasselbe über einen Aufruf gegen dieselbe Route, die die Oberfläche benutzt — und beide sehen danach denselben Stand.

**Warum:** Das Board hat Spalten, aber nichts darin. Alles, wofür KanbanC gebaut wird — Zeiten erfassen, eine WBS importieren, Burndown rechnen —, hängt an der Karte. Ohne sie ist das Board eine Vorführung seiner selbst.

## Szenarien

### US-1: Die Bahnen zeigen, was zu tun ist

**Als** Mensch, der ein Board öffnet
**will ich** die Karten in ihren Spalten sehen,
**damit** ich den Stand der Arbeit ablesen kann, ohne irgendwo nachzuschlagen.

- **Gegeben** ein Board mit den Spalten `Rückstand`, `In Arbeit` und `Fertig`
- **Und** in `Rückstand` liegen die Karten `Migration schreiben`, `Endpunkt bauen` und `Bahn füllen` in dieser Reihenfolge
- **Und** in `In Arbeit` liegt die Karte `Kartenform zeichnen`
- **Wenn** ich das Board öffne
- **Dann** stehen in der Bahn `Rückstand` die drei Karten mit ihren Titeln in genau dieser Reihenfolge
- **Und** in der Bahn `In Arbeit` steht genau die eine Karte
- **Und** keine dieser Karten erscheint in einer anderen Bahn

### US-2: Eine leere Bahn sagt, dass sie leer ist

**Als** Mensch am Board
**will ich** eine Spalte ohne Karten als leer erkennen und mich auf die Reihenfolge verlassen können,
**damit** ich nicht rätsele, ob nichts da ist oder nichts geladen wurde.

- **Gegeben** ein Board, dessen Spalte `Prüfung` keine Karte enthält
- **Wenn** ich das Board öffne
- **Dann** zeigt die Bahn `Prüfung` einen Hinweis darauf, dass sie leer ist, statt einer unbeschrifteten Fläche
- **Wenn** ich die Seite neu lade
- **Dann** stehen die Karten der übrigen Bahnen unverändert in derselben Reihenfolge

### US-3: Eine Aufgabe entsteht dort, wo sie hingehört

**Als** Mensch, der eine neue Aufgabe notiert
**will ich** sie am Fuß der Bahn anlegen, in der sie liegen soll,
**damit** ich die Spalte nicht auswählen muss, auf die ich ohnehin schon zeige.

- **Gegeben** ich habe ein Board offen, dessen Spalte `Bereit` zwei Karten enthält
- **Wenn** ich am Fuß der Bahn `Bereit` eine Karte mit dem Titel `Anzeigegrenze im Spaltenkopf` anlege
- **Dann** erscheint sie als dritte Karte in genau dieser Bahn
- **Und** die beiden vorhandenen Karten stehen unverändert davor
- **Wenn** ich am Fuß einer Bahn eine Anlage beginne und abbreche
- **Dann** entsteht keine Karte

### US-4: Der Agent legt dieselbe Karte an

**Als** KI-Agent, der die Arbeit führt, die er selbst tut
**will ich** eine Karte über die API in einer bestimmten Spalte anlegen,
**damit** das Board nicht hinterherhinkt und niemand meine Arbeit nachtragen muss.

- **Gegeben** es gibt ein Board mit einer Spalte, deren Nummer ich kenne
- **Wenn** ich `POST /api/boards/{boardId}/spalten/{spalteId}/karten` mit einem Titel aufrufe
- **Dann** antwortet die API mit HTTP 201 und der angelegten Karte samt ihrer `KarteId`
- **Und** die Karte steht als letzte ihrer Spalte
- **Und** `GET /api/boards/{boardId}` liefert sie an dieser Stelle
- **Wenn** ein Mensch danach das Board im Browser öffnet
- **Dann** sieht er dieselbe Karte in derselben Bahn

### US-5: Eine Karte ohne Titel entsteht nicht

**Als** Mensch oder Agent, der sich vertippt
**will ich** eine verständliche Zurückweisung statt eines Fehlers,
**damit** ich weiß, was fehlt, und es sofort nachholen kann.

- **Gegeben** ich habe am Fuß einer Bahn die Anlage einer Karte begonnen
- **Wenn** ich sie ohne Titel anlege
- **Dann** erscheint an dieser Bahn eine lesbare Meldung
- **Und** es entsteht keine Karte
- **Und** die Bahn bleibt bedienbar: derselbe Vorgang mit einem Titel legt die Karte danach an
- **Gegeben** ich rufe stattdessen die API auf
- **Wenn** ich eine Karte mit leerem Titel anlege
- **Dann** antwortet sie mit HTTP 400 und einem lesbaren Befund, nicht mit einem Serverfehler
- **Wenn** ich eine Karte in einer Spalte anlege, die es nicht gibt oder die zu einem anderen Board gehört
- **Dann** antwortet sie mit HTTP 404, und es entsteht keine Karte
